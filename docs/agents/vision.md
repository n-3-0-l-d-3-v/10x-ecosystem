# Vision — Creative (Music, Design, Visual, Video, Photography, Ideation)

**Status:** net-new.

## Job

Everything creative, one owner, so it doesn't fragment across agents:

- Music production: DAW project scaffolding/templates (Ardour/LMMS), sample
  organization, mixing notes, theory reference.
- Design/visual: Excalidraw diagramming, Penpot/Inkscape/GIMP/Krita project notes,
  UI/UX critique.
- Video/photography: Kdenlive/Shotcut/DaVinci project organization, Darktable/
  RawTherapee workflows.
- Portfolio: asset generation and organization feeding into the socials/portfolio
  pipeline (Marquee-equivalent reach, but Vision owns the creative asset, not the
  posting).
- Ideation across all of the above — this is the one agent explicitly scoped to
  "creator brainstorming," not just tool orchestration.

## Why one agent, not several

The original plan named "Vision" and a separate "Jarvis-Music/Friday-Music" —
during refinement you explicitly cut the separate music agent because Vision
covers the full creator workflow and a second creative agent would just be
scope-splitting the same job.

## Tools / access

- Read/write to project-specific creative folders (per-DAW-project, per-design-file).
- Writes project notes to the vault (one MOC per creative project, per the
  Obsidian LifeOS structure) — human review gate before anything gets published
  externally.

## Sensitivity tier default

`work` for public creative projects, `private` for anything not ready to share
(unreleased music, draft designs) — set per-project, not globally.
