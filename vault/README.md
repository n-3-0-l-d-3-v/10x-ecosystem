# Vault template (LifeOS)
Open this folder (or your real vault, `devNote`) in Obsidian and copy `Home.md`, `System/Templates/` and `.obsidian/community-plugins.json` in.
Install the listed community plugins, then set Templater's template folder to `System/Templates`.
Agents write to `agents/<Name>/`; the dashboard reads them via Dataview.
Daily-note habit flags (`deepwork`, `dsa`, `workout`, `music`, `writing`) drive the streak table on `Home.md`.
Private material goes under `private/` — agents treat it as local-only tier.
